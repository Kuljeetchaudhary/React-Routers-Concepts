# React Routers Concepts 🚀

A React project created to learn and practice **React Router** concepts through a project-based approach.

## 📌 About the Project

This project focuses on understanding how routing works in React applications using React Router.

It includes different pages and components connected through client-side routing.

## 🛠️ Technologies Used

- React.js
- React Router
- JavaScript
- HTML
- CSS
- Vite

## 📚 Concepts Learned

- React Router setup
- `BrowserRouter`
- `Routes`
- `Route`
- `Link`
- `NavLink`
- Nested Routes
- Layout Components
- Dynamic Routing
- Navigation between pages
- React Components
- Props
- React Hooks
